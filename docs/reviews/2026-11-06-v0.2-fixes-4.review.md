## 1. Correctness risks

1. **The restored-PR blocker remains: `_retire` checks state before an external operation, not atomically with it.**  
   Evidence: `current = self.store.read()[1]["tasks"].get(task["id"]) or {}` precedes `self.gh.pull(number)` and `self.gh.close_pr(number)`.  
   A valid interleaving is:
   - `hold` clears the current PR and saves it in `held_from`.
   - A delayed old-attempt `_open_pr` is refused attachment and calls `_retire`.
   - `_retire` reads the held state, where `pr` is `None`.
   - The checkout fails; `unhold` restores the PR.
   - `_retire` closes that restored PR.  
   Closing during the hold and restoring afterward also fails. A fresh read narrows the window; it does not remove it.

2. **The new regression test does not exercise that remaining interleaving.**  
   Evidence: `self.failing_take(self.a, task["id"])` completes before either `self.talk(self.b)._open_pr(...)` or `self.talk(self.b)._retire(...)`.  
   It proves protection when rollback has already completed before retirement starts, not protection while rollback and retirement overlap.

3. **An ancestry-check error is classified as non-ancestry, potentially permitting replay after an ambiguous push.**  
   Evidence: `return git(..., "merge-base", "--is-ancestor", sha, tip, check=False).returncode == 0`.  
   Exit status 1 means non-ancestor; other failure statuses should abort recovery rather than fall through to `return False` and rerun the mutation. Under a local Git/object failure, the current classification can defeat the new recovery safeguard.

4. **Retirement comments are retryable but not globally duplicate-proof.**  
   Evidence: `if not any(note in ... for c in self.gh.issue_comments(number)):` followed by `self.gh.comment(...)`.  
   Two clones can both observe no marker and post it. The lock in `_flush` is a local file lock, and `_open_pr` also calls `_retire` directly. This is a tolerable alpha limitation if documented, not an exactly-once guarantee.

## 2. Hidden assumptions

1. **Push recovery assumes nobody rewrites or deletes the state branch outside this protocol.**  
   Evidence: `"""State history is append-only ..."""` and `args += ["-p", parent]`.  
   These establish append-only history for the supplied writer, not for repository administrators or other clients. A landed commit removed by a rewrite is indistinguishable here from a mutation that never landed.

2. **Retirement treats a temporarily absent PR link as permission to close permanently.**  
   Evidence: `retire_pr(task)` sets `task["pr"] = None`, while `unhold` explicitly restores the saved fields.  
   The design therefore depends on retirement not overlapping a reversible hold, but no such exclusion is shown.

3. **Marker-based recovery assumes GitHub comment enumeration is complete and sufficiently current.**  
   Evidence: `_retire` searches `self.gh.issue_comments(number)` before commenting.  
   Pagination and consistency behavior of that wrapper are not supplied.

## 3. Design decisions to challenge

1. **I would replace retirement eligibility based on current state with an explicit irreversible retirement transition.**  
   Evidence: `task["held_from"] = ...` is immediately followed by `old = retire_pr(task)`.  
   Consider a provisional hold that preserves the old PR’s protected status until checkout succeeds; success then commits retirement eligibility, while failure rolls back without ever authorizing closure. Retirement must check that durable eligibility, not merely whether the PR is currently linked.

2. **I would make ancestry recovery distinguish “false” from “unknown.”**  
   Evidence: `...returncode == 0`.  
   Treat 0 as landed, 1 as not landed, and every other status as an error requiring recovery rather than mutation replay.

3. **I would weigh a shared retirement work queue against actor-local event delivery.**  
   Evidence: pending events require `ev.get("worker") == self.worker`.  
   The accepted dependency on the acting clone returning is defensible for an alpha, but a shared, claimable outbox would avoid leaving remote cleanup dependent on one clone’s survival.
